# Design Decisions

Version: 1.0

Primary source of truth: `docs/PROJECT_CONTEXT.md` Version 2.0.

Secondary governance source: `docs/REVIEWER_TRACEABILITY_MATRIX.md`.

This document records approved design decisions for the clean MMSDP-XAI project. It does not claim completed implementation, final algorithms, final dataset statistics, or completed experiments.

Decision status vocabulary:

- `Approved`: part of the project baseline.
- `Approved with controls`: approved, but only with required quality gates.
- `Conditional`: allowed only when explicit criteria are met.
- `Journal-dependent`: editorial and submission-target specific.
