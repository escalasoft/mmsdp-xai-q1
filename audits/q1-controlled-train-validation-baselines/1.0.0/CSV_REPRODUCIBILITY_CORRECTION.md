# Sprint 49-R1 CSV line-ending reproducibility correction

**Classification:** `PASS_49_R1_CSV_REPRODUCIBILITY_CORRECTION`

## Root cause and correction

All nine campaign CSV artifacts share `_write_csv` in `src/experimentation/q1_controlled_result_campaign.py`. The writer opened files with `newline=""`, but `csv.DictWriter` retained the Excel dialect's default CRLF record terminator. The implementation now passes `lineterminator="\n"` explicitly. A focused regression asserts the exact emitted bytes and absence of carriage returns.

The artifacts were regenerated by loading the frozen `condition_results.json` and invoking the campaign's shared CSV writer and table builders. Model fitting and hyperparameter selection were not rerun.
